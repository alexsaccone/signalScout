# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React on GitHub Pages. A scheduled Python job generates a read-only snapshot.

## Product Purpose

SignalScout helps a user check upcoming sports odds and inspect reviewed cross-venue price opportunities. The dashboard shows the source and freshness of the figures.

## Capabilities and Constraints

Venue odds and estimated net returns have different meanings. Only pairs with unchanged, reviewed settlement terms can be priced. Quote expiration and failed refreshes must remain visible to readers.
